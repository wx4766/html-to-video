# 风格库 · 8 种视觉语言

同一段内容，换一种视觉语言，就是另一支片。

`assets/lib/styles.js` 把「风格」从「版式」里拆了出来：版式决定**画什么**（标题、要点、条形图），
风格决定**长什么样**（纸是哪种纸、墨是哪种墨、线多粗、字多紧、入场怎么动、签名元素是什么）。

于是 11 个版式模板 × 8 种风格 = 88 种观感，而不是写 88 个模板。

```bash
# 一句话换风格（也可以写中文名）
bash assets/render.sh assets/style-film.html --duration=13 --theme=chalk
bash assets/render.sh assets/style-film.html --duration=13 --theme=水墨 --width=1080 --height=1920
```

## 八种风格

### 01 · 孔版印刷 Riso Print　`riso`　（默认）

米白纸 + 荧光粉 / 蓝 / 绿三套网点（各带真实印刷网角 75° / 15° / 45°）+ 标题套印错位。
**辨识度最高的一种**，看一眼就知道是"设计过的"。

- 适合：观点输出、数据对比、独立杂志感的产品片
- 签名元素：三色网点、标题的双色错版
- 忌：大面积纯色平涂（会把网点压死）
- 实测：竖屏 1080×1920 下网点会自动变密，像真实印刷的细网，反而更好看

### 02 · 剪纸拼贴 Cut Paper　`cutpaper`

牛皮纸底 + 四边手撕的纸片 + 锐利硬投影 + 两张纸叠着的厚度 + 字体投影高光。

- 适合：故事、人物、教育、有温度的产品叙事
- 签名元素：手撕毛边、双纸叠层、文字像"贴上去"的
- 忌：圆角（一出现就不像剪纸了）
- 内容区：`card()` 会内缩一圈，纸片边缘不压字

### 03 · 工程蓝图 Blueprint　`blueprint`

深蓝底 + 20/100px 双层格网（会随片缓慢平移）+ 白色细线 + 四角十字定位标记 + 等宽字。
外框 + 内框的图框结构，是工程图的真实规矩。

- 适合：技术讲解、架构图、API/SDK、硬核产品
- 签名元素：图框、十字标记、条形下方的刻度线
- 忌：圆角、阴影、任何"软"的东西
- 内容区：`card()` 内缩 34px，四角十字标不会被字压住

### 04 · 黑板粉笔 Chalkboard　`chalk`

墨绿黑板（带擦了又写的旧痕）+ 双线抖动笔触 + 粉尘辉光 + 楷体。
条形图是十几道粗笔触叠出来的，不是实心矩形。

- 适合：教学、科普、给小朋友讲、有"讲师在写"的现场感
- 签名元素：手画框（四角不闭合）、粉笔条、粉笔槽投影
- 忌：严格对齐太狠（越整齐越假）、直角卡片
- 手抖：`SV.boil(ST, t, i, 2.2)` 每 0.1 秒抖一次，是纯函数，不会破坏确定性

### 05 · 等距线稿 Isometric　`isometric`

白底 + 极淡的等距参考网格 + 1.6px 精确线稿 + 白面遮挡 + 一个深色强调。
`card()` 画的是**真立体块**（顶面 + 左面 + 右面），不是矩形加阴影。

- 适合：机制解释、系统结构、流程、产品原理
- 签名元素：2:1 等距积木、白面遮住后面的东西
- 注意：内容框只给**顶面**（一个菱形带）。`card()` 返回的 `h` 只有方块高的 48%，
  塞两行字会压到棱线上 —— 一行大字是它的正确用法
- 忌：渐变、发光、圆角

### 06 · 霓虹复古 Synthwave　`synthwave`

紫黑渐变天空 + 右侧条纹太阳 + 透视地面网格（横向线按平方分布，近疏远密）+ CRT 扫描线 + 色差。

- 适合：音乐、游戏、复古科技、发布会倒计时
- 签名元素：条纹太阳、网格地平线、地平线辉光
- 注意：标题色差只错开 0.4% 字号。错到 0.8% 中文会"发抖"，像信号干扰而不是 CRT 味
- 忌：浅色内容（整个风格靠发光撑着）

### 07 · 瑞士网格 Swiss Grid　`swiss`

白底 + 12 栏网格 + 超大字号（占画面 1/3）+ 单一信号红 + 零圆角。
全靠排版张力和节奏，没有一处装饰。

- 适合：品牌片、观点、发布会开场、极简产品
- 签名元素：左边缘的栏位刻度、纯色块
- 注意：色块里的字必须是反白。`card()` 会返回 `ink` 字段，照着用
- 忌：任何阴影、渐变、圆角、表情

### 08 · 水墨宣纸 Ink Wash　`ink`

宣纸（纤维 + 噪点）+ 墨色上浓下淡 + 三层洇墨 + 朱红印章色 + 大留白。

- 适合：国风、文化、历史、人物、茶/酒/文旅
- 签名元素：泼墨块（边缘毛、有飞白）、标题的洇墨
- 注意：淡墨块（非 accent）和浓墨块（accent）是两套透明度。
  淡墨上放黑字、浓墨上放反白字，`card()` 返回的 `ink` 已经处理好了
- 忌：饱和的彩色、细密的机械线条

## 在代码里用

```html
<script src="../lib/styles.js"></script>
<script>
const ST = SV.get('riso');        // 也吃中文名：SV.get('水墨')
const TH = ST.theme;              // 兼容 themes.js 的字段

SV.bg(g, ST, W, H, t);            // 背景（纸纹 / 网格 / 透视地面）
SV.text(g, ST, '标题', x, y, size, { kind: 'display' });
const box = SV.card(g, ST, { x, y, w, h }, { S: SF, accent: true });
//   ↑ box = { x, y, w, h, ink } —— 内容安全框 + 该用的文字色
SV.bar(g, ST, { x, y, w, h }, p); // 条形，(0..1) 进度
SV.overlay(g, ST, W, H, t);       // 覆盖层：扫描线 / 颗粒 / 暗角，画在最后
</script>
```

**四条约定**，违反任意一条都会出问题：

1. **`card()` 一定要用它的返回值排版**。每种风格能放字的地方不一样（等距只给顶面、
   水墨只给内圈、瑞士要反白），拿原始 `box` 硬排，字一定压边。
2. **每个镜头的 `draw` 自己画满背景**。`SC.paint` 里 `paintShot()` 会先 `clearRect` ——
   少这一步，背景就是黑的。
3. **`overlay` 放在最外层**，在所有镜头之上。放进镜头里，转场时扫描线会跟着淡入淡出。
4. **别自己写 `Math.random()`**。纹理噪点走 `SV.rng(seed)`，手抖走 `SV.boil()` ——
   都是纯函数，换台机器渲出来一模一样。

## 已有的 11 个模板怎么吃到风格

它们不需要改代码，只认 `--theme`：

```bash
bash assets/render.sh assets/templates/bar-chart.html --theme=blueprint --duration=6
bash assets/render.sh assets/templates/explainer.html --theme=riso --duration=18
bash assets/render.sh assets/templates/vertical-card.html --theme=synthwave \
  --width=1080 --height=1920 --duration=6
```

机制只有一句：模板背景层里判断 `TH.__style`，有就调 `SV.bgCached(...)` 换成风格底，
没有就走原来的渐变。

```js
function bgLayer(g2, t) {
  if (TRANSPARENT) return;
  if (TH.__style && window.SV) {          // ← 风格底优先
    SV.bgCached(g2, TH.__style, W, H, 0, {}, 0);
    return;
  }
  /* ……原来的渐变 + 光斑 + 网格…… */
}
```

**`styles.js` 不用在模板里引**。渲染器启动时会把它注进页面（`addInitScript`），
所以模板可以单独拷走、可以放进临时目录跑测试，不会因为 `../lib/styles.js` 404 被判定失败。
浏览器直接打开模板时没有 `SV`，自动退回原渐变 —— 那时也用不上 `--theme`。

**风格与模板的匹配建议**（实测下来的感受，不是硬规则）：

| 模板 | 顺手的风格 | 别用 |
|---|---|---|
| `explainer` 讲解片 | 粉笔 / 蓝图 / 剪纸 | 霓虹（人物和发光底色打架） |
| `bar-chart` / `line-chart` 数据 | 蓝图 / 瑞士 / 孔版 | 水墨（细线会化开） |
| `number-counter` 大数字 | 瑞士 / 等距 / 霓虹 | 剪纸（数字贴纸感太强） |
| `timeline` / `flow-steps` 流程 | 蓝图 / 等距 | 霓虹 |
| `subtitle-card` / `vertical-subtitle` 字幕 | 粉笔 / 孔版 / 霓虹 | 瑞士（字号太大会顶字幕带） |
| `title-card` 片头 | 全部 | — |
| `compare` 对比 | 瑞士 / 孔版 | 水墨 |

字幕类模板要留意底部字幕安全区：换浅色风格后，字幕条的对比度会变，建议出片后看一眼
最后 15% 的画面。

## 加一种自己的风格

在 `assets/lib/styles.js` 的 `STYLES` 里加一项，抄最接近的那个改。必须实现：

| 字段 | 作用 | 不写会怎样 |
|---|---|---|
| `id / cn / en / dark / tags` | 目录信息，`SV.list()` 用 | 列表里查不到 |
| `theme` | 11 个基础色 + 5 个可选项（见 themes.js） | 模板取不到色，报错 |
| `type` | `display / body / mono` 字体族、字重、字距 | 文字排版全乱 |
| `bg(g,W,H,t,o)` | 底面 | 背景透明，转场时闪 |
| `overlay(g,W,H,t,o)` | 覆盖层，可为 `null` | 少一层质感 |
| `text(g,txt,x,y,size,o)` | 文字画法 | 没有风格化的字 |
| `card(g,box,o)` | 面，**必须返回 `{x,y,w,h,ink}`** | 调用方报 `reading 'x' of undefined` |
| `bar(g,box,p,o)` | 条 | 图表没风格 |
| `boil(t,i,amp)` | 手抖，不要就返回 0 | 少一点手作感 |
| `motion` | `{ enter, overshoot, ease }` | 入场节奏跟风格不搭 |

写完跑一次八宫格，眼睛确认，再进模板：

```bash
node scripts/render-video-seek.js assets/style-gallery.html --stills=0.5 --width=1920 --height=1080
```

**风格好不好，看三件事**：

- 只看 0.3 秒，能认出是哪个风格吗？（识别度）
- 换成长中文标题还成立吗？（中文适配）
- 灰掉以后还有层次吗？（不靠颜色的结构）
